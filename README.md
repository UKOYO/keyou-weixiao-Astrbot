# 星渊 API 监控与工具账本（astrbot_plugin_syuan_monitor）

实时监控星渊 API（Syuan API / OneAPI）中转站的 Token 消费额度、模型调用分布、请求耗时，并分类统计 AstrBot 本地各项工具与插件的调用次数、花费估算及驱动 LLM。

作者：唯笑 & keyou · 版本 v1.2.0

---

## 功能特性

1. **中转站实时监控**：
   - 自动读取 `cmd_config.json` 中配置的星渊 API Key，拉取最近调用日志；也可在插件配置里手填 API Key，或再配一个账号访问令牌 + 用户 ID 换取账号级全量日志。
   - 统计中转总调用量、总花费估算（按 1 USD ≈ 500,000 Quota 换算）与平均响应延迟。
   - 模型维度明细：各模型的调用次数、总花费与平均响应时间。
   - 实时请求流水：展示每次调用的时间、模型、耗时、Prompt/Completion Token 及具体扣费。
   - **自动翻页补齐**：上游把单页 `page_size` 夹在 100 条，插件会自动连续翻页拼接，所以「昨天全天」这类大窗口不会再只拿到一页就被截断。

2. **插件与工具分类手账**：
   - 自动解析 AstrBot 本地日志（`astrbot.log`）中的工具触发事件。
   - 中文友好显示：将内部工具 ID 映射为中文插件与功能名，并在下方标注底层英文 ID。
   - 驱动 LLM 标注：清晰列出每个工具执行或决策时所使用的主要大模型（如 `gemini-3.8-flash`、`gemini-3.7-flash (VLM)` 等）。
   - 统计每个工具的触发频次、消耗上下文 Token 估算与折算成本。

3. **数据只读不落盘**：
   - 每次统计都直接从中转站接口实时拉取，不在本地写入任何日志副本或历史缓存文件。
   - 仅保留数秒内存缓存用于削峰防抖（由 `refresh_seconds` 控制），进程重启即自动清空。

4. **报错尖峰提醒（可选）**：
   - 开启后按固定间隔巡检，最近十分钟报错条数超过阈值时主动私聊播报，并带冷却时间避免刷屏。

5. **双端查看与呈现**：
   - **聊天指令与手账卡片**：支持发送 `api账本` / `api统计` / `api监控`，实时渲染温馨手账风格的卡片长图。
   - **每日自动推送**：每天清晨 06:00 自动生成前一日消费与调用手账，主动推送给主要用户。
   - **后台可视化 WebUI**：内置 Dashboard 扩展页面，可直接在 AstrBot 管理面板打开交互式表格，支持关键词即时筛选与「实时 / 今日 / 昨日」时间窗切换。
   - **排版优化**：修正文字被侧栏挤压重叠的问题，过长的名称与模型 ID 会自动折行或省略，保证卡片与表格都能完整读完。

## 页面访问 (WebUI)

本插件符合 AstrBot 官方 WebUI 规范：
- 进入 AstrBot 管理后台 -> **插件** 列表 -> 找到 **星渊账本 (astrbot_plugin_syuan_monitor)**。
- 点击插件拓展页面的 **pages/dashboard** 即可进入可视化大屏。

## 配置项速览

| 配置项 | 说明 |
| --- | --- |
| `api_base` | 中转站地址，默认 `https://api.syuan.org` |
| `access_token` / `user_id` | 账号级访问令牌与用户 ID，用于拉全量日志 |
| `api_key` | 星渊 API Key，留空时自动从 `cmd_config.json` 抓取 |
| `refresh_seconds` | 内存缓存秒数，即实时轮询的最小拉取间隔 |
| `log_page_size` | 实时界面每次拉取的日志条数 |
| `daily_page_size` | 每日日报拉取的日志条数，需覆盖昨天全天 |
| `alert_enabled` 等 | 报错尖峰提醒的开关、巡检间隔、阈值与冷却 |

## Web API 接口

路由前缀为 `/astrbot_plugin_syuan_monitor/api`（经 Bridge 安全调用）：

- `GET /overview`：总调用、总花费、平均延迟、缓存更新时间等总览。
- `GET /models`：各模型的调用次数、总花费与平均耗时列表。
- `GET /tools`：各插件工具的中文名、原始 ID、驱动 LLM、触发频次、Token 及费用。
- `GET /logs`：最近的中转站调用原始流水明细，支持 `range=live|today|yesterday` 时间窗与翻页。
- `GET /card`：手账卡片 PNG 的 Base64 Data URL，方便前端直接渲染预览。
